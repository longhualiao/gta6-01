Solmar City is a complete open-world crime game that plays offline in a desktop browser: a sun-soaked coastal city to explore on foot and by car, with traffic and pedestrians, cars to steal, a five-star wanted system with pursuing police, six story missions, combat, a HUD with a live minimap, and a save that persists between visits. Built with plain HTML, CSS and JavaScript — no libraries, no build step, no network requests.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

WASD to move and drive, E to steal and enter cars, mouse to aim, click to shoot, Q to swap weapons, Esc to pause. Start a mission with Enter and follow the marker: steal a car, run jobs for Rosa Delgado, lose the cops, and own the city.
